## `elixir/`

The site alkeyword.com served from 2025-11-19 until 2026-08-13: **"Alkeyword — Observable Type
Safety for Elixir"**, a landing page plus `documentation.html` and 22 files under `docs/`.

It is a different product from the one the domain now carries. The name is what they share: `al-`
as in alchemy, algebra, algorithm.

Kept rather than deleted so existing links resolve instead of 404ing. Served under
`X-Robots-Tag: noindex` — see `_headers` at the repository root for why that matters here
specifically.
